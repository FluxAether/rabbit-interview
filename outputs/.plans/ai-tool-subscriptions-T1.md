# T1 — 通用 AI 助手订阅

## Objective
截至 2026-08-31，比较主流通用 AI 助手的个人、团队与企业订阅，并明确它们与开发者 API 计费的边界。

## Scope
优先覆盖 ChatGPT、Claude、Gemini、Microsoft Copilot、Perplexity。只纳入可由官方资料验证的当前方案；计划名称或可售性因地区不同须明确标注。

## Evidence
- 官方定价、套餐帮助、使用额度/公平使用、取消退款、团队与企业管理页面。
- 记录月付/年付、币种、税费/地区说明、额度性质、超限行为、数据使用承诺。
- 明确消费订阅是否包含 API credits；不要推断。
- HTML/官方文档优先；不解析 PDF。失效或无法核验的 URL 放入 rejected sources。

## Deliverable
写入 `outputs/.drafts/ai-tool-subscriptions-research-assistants.md`：比较表、关键发现、精确 URL、访问日期、来源接受/拒绝清单、仍不确定之处。不要给 RabbitInterview 最终方案。
