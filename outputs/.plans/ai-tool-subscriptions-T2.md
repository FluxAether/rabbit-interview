# T2 — AI 编程工具订阅

## Objective
截至 2026-08-31，比较主流 AI 编程工具的个人、团队与企业席位、额度和超额计费。

## Scope
优先覆盖 GitHub Copilot、Cursor、Windsurf；视官方信息质量补充 Claude Code、Gemini Code Assist 或其他高相关工具。区分 IDE/CLI 席位与可嵌入产品的 API。

## Evidence
- 官方 pricing、计划额度、premium requests/credits、速率或超额规则、月付/年付、团队管理、隐私与企业条款。
- 记录“无限”等营销词背后的限制；不能确认时降级表述。
- 明确席位是否允许将模型能力转售或嵌入终端产品；不要把开发席位当生产 API。
- HTML/官方文档优先；不解析 PDF。失效或无法核验的 URL放入 rejected sources。

## Deliverable
写入 `outputs/.drafts/ai-tool-subscriptions-research-coding.md`：交叉比较表、关键差异、精确 URL、访问日期、来源接受/拒绝清单和不确定项。不要给 RabbitInterview 最终方案。
