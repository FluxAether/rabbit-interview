# T4 — 治理、隐私与商业约束

## Objective
截至 2026-08-31，跨供应商比较订阅模式背后的数据治理、管理员能力、SLA、区域和商业约束。

## Scope
围绕通用助手、AI 编程工具和开发者 API 的共性维度：训练数据使用/退出、保留期、SSO/SCIM/RBAC、审计、合同/SLA、数据驻留、年付折扣、取消退款、税费地区差异、供应商锁定和成本可预测性。

## Evidence
- 优先官方隐私、数据控制、企业、安全、服务条款、SLA、billing 帮助页面。
- 严格区分个人、团队/商业、企业和 API 数据政策；不要将一类政策泛化到另一类。
- 对缺少公开价格或需询价的方案标记“custom/contact sales”，不估价。
- HTML/官方文档优先；不解析 PDF。失效或无法核验的 URL 放入 rejected sources。

## Deliverable
写入 `outputs/.drafts/ai-tool-subscriptions-research-governance.md`：治理比较框架、已验证差异、精确 URL、访问日期、来源接受/拒绝清单、争议与未知项。不要给 RabbitInterview 最终方案。
