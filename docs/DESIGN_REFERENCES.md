## Key Visual Language
- Clean light UI with soft cards
- Indigo accent (#6366f1)
- Left sidebar navigation with active purple indicator
- Generous padding, rounded-2xl / 3xl cards
- Circular score indicators
- Structured suggestion cards
- Glassmorphic floating assistant panel

Every new component or screen should be compared against these references.
