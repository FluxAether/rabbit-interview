# 隐形助手优化与验收

2026-09-05，基于用户确认后的工作区修改，未替换 `/Applications/OnCue.app`，未中断正在进行的录音。

## 已修改

- 音量独立订阅和轻量事件同步；计时、输入、复制反馈与聊天列表分离。隐藏浮窗暂停列表更新，显示时接收最新内容。
- 可变高度虚拟列表只挂载视口附近的消息；使用稳定问题 ID 和消息对象复用。保留当前会话全部消息及原有归档数据范围，suggestions 的 40 条上限不变。
- 问题与回答排序改为线性扫描；前台和后台回答均按 40 ms 合并发布，首段、完成及取消立即发布。
- 恢复快照只随可恢复内容变动保存；串行写入，归档前完成待保存内容，避免归档删除后旧备份重新写入。
- 去掉重复摘要与正文；长回答默认收起，可展开全文、复制全文。限制阅读行宽，增大文字与操作目标，完善开关与展开状态的无障碍语义。
- 合并重复标题、监听状态和浮窗入口，缩小波形；仅保留总音量，状态由真实会话/生成状态驱动。固定区明确“重答当前问题”，移除底部重复入口。
- 离开底部显示“回到最新”；新增消息按 ID 计数，隐藏气泡不计入未读。阅读历史、早期补答、字号变化与末尾跟随共享滚动位置处理。
- 音频配置解释录音期间为何禁用，技术信息放入原生折叠详情；同步英文、简体中文和繁体中文。

这是本地浏览器夹具与 Node 源码函数的对照；不等同于已安装版本的原生 WebView 帧率。

- `rtk npm run verify:copilot`：275 项通过，包括流式合并、末尾文字、取消、后台重答、恢复保存及浮窗事件边界。
- `rtk npm run build`：通过。既有大包和动态/静态导入提示仍在。
- `rtk cargo test --manifest-path src-tauri/Cargo.toml`：29 项通过。首次全量运行的 `reports_a_sidecar_that_exits_during_startup` 出现一次时序失败，单项复跑及全量复跑通过；没有修改 Rust。
- `rtk git diff --check`：通过。
- 浏览器长会话：从 1,000 条增加至 1,006 条，主窗口双向阅读的 16 项检查全部通过；包括首条历史可达、流式跟随、未读计数、隐藏本人气泡、补答保持位置、展开状态跨虚拟挂载保留和字号调整。
- 浮窗模式的 80 条消息、20 次音量更新检查通过：挂载 6 行，消息行渲染 0 次。浮窗跨 WebView 的引用复用、音量/快照事件顺序、过期事件和监听清理已通过实际客户端函数检查。
- 验证限制：随后界面工具连接中断，报 `Browser is not available` / `Sky Computer Use native pipe startup failed`，重置和重连均失败。因此浮窗长会话双向滚动、隐藏后显示、最终页面截图，以及安装版原生 WebView 帧率均未完成实测；保留可运行的验证入口，未把这些列为已通过。
