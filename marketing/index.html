FAQ 与使用须知

开始前，先确认这些条件

为什么需要我自己的 API Key？

Rabbit Interview 不代售语音或模型额度。实时语音需要 Deepgram API Key，回答建议需要 Groq、OpenAI、Anthropic 或 Gemini 中任一供应商的 API Key。相关费用与数据政策由供应商决定。

浮窗能保证对方完全看不到吗？

不能。客户端只会调用操作系统提供的捕获保护并显示状态，不承诺对所有录屏、会议或监考软件有效，也不防焦点检测、进程扫描或物理摄像头。

我的简历、录音和 API Key 保存在哪里？

面试记录、简历工作区、录音和 API Key 保存在本机应用数据中。启用语音和模型功能后，相应音频与文本会直接发往所选供应商。

为什么安装时会出现系统安全警告？

v0.7.0 是未使用 Apple Developer ID、公证和 Windows Authenticode 签名的公开测试版。仅从本页链接下载，核对 SHA-256 校验值，并按上方系统图形界面说明操作。

可以在任何面试或在线测评中使用吗？

不可以。请事先查看面试方、学校或测评平台的规则，仅在明确允许辅助工具时使用。
